# Summary 
Code to convert string expressions between infix, prefix, and postfix notation iteratively using Stacks with Python version 3.10.9.


# Usage
To convert the input cases held in input_output/input.txt, the user must run the lab_1.py function. This will read the input cases from the input file, determine the format of the input case, convert the expression, and write the converted expression to output file. 

If an input case is infix, it will be converted to prefix. If an input case is prefix, it will be converted to postfix and infix. If an input case is postfix, it will be converted to prefix and infix. 

If an error is encountered, the error is written to the output file. 


# How to Run 
1. EDITOR 
   Open the lab_1 directory in VSCode editor (or editor of choice).
   Open lab_1.py and run the file. 

2. COMMAND LINE 
   cd to lab_1 root directory
   Run command: python lab_1.py 


# File/Directory Descriptions 
input_output/   
    - input.txt: Text file that contains various input cases in either infix, prefix, or postfix form. One input per line.
    - output_example.txt: Example output text file that I generated by running lab_1.py. When user runs lab_1.py, the script will generate output.txt that will be saved in this directory. 
    - output.txt: Not initially included in this directory. This file will be generated once the user runs lab_1.py. Each time user runs lab_1.py, this file will be overwritten. 

lab_1.py
    - Contains function to read input cases from input_output/input.txt file. 
    - Contains functions to identify the format of the input string and convert it to infix, prefix, or postfix depending on its initial format. 
    - Contains main function that writes converted strings to output text tile, input_output/output.text
    - Handles errors. 

ArrayStack.py 
    - Contains class definition for ArrayStack class. ArrayStack class is built upon Python List class for storage and follows LIFO principle.
